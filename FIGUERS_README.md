# TF KO Figure Guide

This directory contains visualizations generated by CausalBridge for single-TF KO or multi-TF combined KO results. Red in figures generally indicates activation or upregulation, blue indicates inhibition or downregulation, and gray indicates stability, missingness, or no observation; consult each figure’s description for the precise meaning. Each output file retains only one main title at the top of the figure; method and filtering notes are recorded uniformly in this document.

## Script Entry Points

- Single TF KO: `Rscript visualize_perturbation.R RESULT_DIR`
- Multi-TF combined KO: `Rscript visualize_multi_tf_perturbation.R RESULT_DIR`
- Current combined-KO example: `Rscript visualize_multi_tf_perturbation.R results/test/GATA1_KLF1`

The combined-KO script parses genes in `target_gene` separated by commas or plus signs into the KO TF set. Edges emitted by any KO TF in a pathway are direct paths; only TFs that are not in the KO set and have a complete “KO TF → intermediate TF → peak → target gene” chain belong to the intermediate TFs. The figure uses one combined-KO node to summarize contributions from multiple starting points.

At the beginning of `visualize_multi_tf_perturbation.R` are three directly editable configuration items: `RESULT_DIR` is the input results directory, `OUTPUT_DIR` is the image output directory, and `PATHWAY_GENES` is the specified gene displayed in `pathway_specified.png`. `PATHWAY_GENES` may be set to one gene, a vector of multiple genes, or `NULL` to automatically select the five genes with the largest absolute effects.

## 1. `volcano.png`: Perturbation Effects and Model-Fit Quality

This is not a traditional volcano plot with `-log10(p)` on the y-axis, but a two-dimensional scatter plot that simultaneously shows gene perturbation effects and the credibility of the ATAC→RNA model.

- x-axis: mean RNA change, `ΔRNA (log2 fold change)`.
- y-axis: mean fit quality `R²` of the corresponding gene’s ATAC→RNA transfer function.
- Red points: `log2FC > 1`, defined as strong upregulation.
- Blue points: `log2FC < -1`, defined as strong downregulation.
- Gray points: finite values with `|log2FC| ≤ 1`, defined as stable or weak effects; missing or `NaN` values must not be interpreted as weak effects.
- Vertical dashed lines: effect-classification thresholds `log2FC = ±1`.
- Horizontal dashed line: reference line `R² = 0.5`.
- Gene labels: preferentially label genes with high `|log2FC| × R²`, namely genes with both large effects and strong model support.

When interpreting the plot, prioritize the upper-right or upper-left regions: these genes have both large expression changes and high ATAC→RNA fit quality. This figure does not express statistical significance; the y-axis must not be interpreted as a p-value.

## 2. `distribution.png`: Perturbation-Effect Distribution and Effect Classification

This figure consists of two panels.

### Left: Effect Distribution

- x-axis: mean `ΔRNA` of all affected genes.
- y-axis: number of genes in the corresponding interval.
- Blue bars: negative effects, namely downregulation.
- Red bars: positive effects, namely upregulation.
- Solid black line: zero-effect position.
- Dashed red line: median effect across all genes.

This panel is used to determine whether the global response after KO is biased toward upregulation or downregulation and whether the effect distribution has a long tail or obvious skew.

### Right: Effect Classification

- Up: `log2FC > 1`.
- Down: `log2FC < -1`.
- Stable: `|log2FC| ≤ 1`.

This classification is based only on effect-size thresholds, not on a statistical-significance test; therefore the title uses **Effect Classification**.

The corresponding figure for ATAC accessibility results is Section 9, `atac_distribution.png`.

## 3. `cluster_heatmap.png`: Differential Effects Across Cell Clusters

This heatmap shows the direction and magnitude of gene responses to RUNX1 KO in different cell clusters.

- Rows: affected genes.
- Columns: cell clusters.
- Red: RNA upregulation.
- Blue: RNA downregulation.
- White: observed effects close to 0.
- Gray: no usable result or no observation for the gene in the corresponding cell cluster.
- Color scale: the color mapping may be limited to `[-3, 3]` during plotting to prevent extreme values from compressing the main color differences; this is a **visualization-only colour cap**, does not modify effect values in the CSV, and is not data clipping.

The heatmap prioritizes genes whose effects differ substantially among clusters. Genes are ranked by the following composite score:
The original figure no longer displays a subtitle for the ranking rule; the precise calculation follows this document. Gray cells indicate no observation and are excluded from calculating `effect_range` and `effect_sd` among the clusters observed for that gene.

```text
heterogeneity_score = coverage × (effect_range + effect_sd) × direction_bonus
```

Where:

- `coverage`: the proportion of cell clusters with results among all cell clusters, used to suppress incidental extremes appearing in only a few clusters.
- `effect_range`: the difference between the maximum and minimum `ΔRNA` across clusters.
- `effect_sd`: the standard deviation of `ΔRNA` across clusters.
- `direction_bonus`: `1.25` if the same gene is both upregulated and downregulated in different clusters; otherwise `1`.

Thus, genes near the top usually have larger magnitude differences or direction reversals among clusters. Gray and white have different meanings; missing results must not be interpreted as zero effects.

## 4. `pathway_specified.png`: Regulatory Pathway for Specified Genes

This figure uses the same **radial cluster hierarchy** logic as the automatic pathway figures in Section 5. When `PATHWAY_GENES` is one gene, one radial panel is output; when it contains multiple genes, each gene is drawn independently in its own panel and the paths of different genes are never merged.

Each panel proceeds outward from the center:

```text
KO TF → Target peak → Intermediate TF (indirect path) → TF peak → terminal effect within cluster
                                                               ↓
                                                     GLOBAL WEIGHTED OUTCOME
```

- Center circle: KO TF; `C0`, `C1`, and similar labels near the circle’s edge correspond to cluster sectors.
- Each cluster is a sector. Sectors have a base area; on top of this, angle and radial depth increase according to the log-compressed `|ΔRNA|` value in that cluster. Weak effects, zero effects, and missing clusters therefore remain legible, while strong-effect clusters occupy more area.
- Color-block layers, in order, represent target peak, intermediate TF, TF peak, and terminal effect. Arrow channels separate peak/TF blocks; direct paths crossing intermediate-layer blocks are shown as arcs, while unobstructed direct paths and indirect paths use straight lines.
- Terminal-effect blocks fill the outermost layer of their sector. Observed terminal effects from each cluster flow through neutral connectors outside the sectors into `GLOBAL WEIGHTED OUTCOME` below; the card’s value comes directly from `perturbation_merged.csv::delta_rna_signed` and is a weighted aggregate, not a simple sum of pathway contributions shown in the figure.
- Terminal-effect blocks are colored using that cluster’s `delta_rna` in `perturbation_results.csv`; observed responses close to zero are shown as neutral blocks.
- If a cluster has retained paths but no corresponding finite `delta_rna` in `perturbation_results.csv` (including `NaN`), the terminal effect is shown as gray/missing; it must not be rendered as near-zero (`ΔRNA +0.00`).
- Only when a cluster has neither a terminal-effect result nor any constructible path is a `Missing` outlined placeholder block shown; paths with invalid terminal effects must be clearly distinguished as missing/NaN.

Visual encoding:

- Orange center: KO TF.
- Purple arc blocks: intermediate TF; the TF name is written directly in the block.
- Light-gray arc blocks: peak.
- Letters in peak blocks correspond to the annotation panel on the right; the annotation panel gives the complete peak coordinates (`chr:start-end`).
- Terminal effects and the global card: light red indicates RNA upregulation, light blue indicates RNA downregulation, and light gray indicates zero or near-zero effects; white outlined blocks indicate only the `Missing` state with neither a terminal-effect result nor a retained path.
- Edge colors indicate only intrinsic regulatory direction: red is Positive, blue is Negative, and gray is Uncertain. Edge color does not indicate the final RNA response direction.

An indirect path must have a complete `KO TF → peak A → intermediate TF → peak B → affected gene` chain within the same cluster; a direct path is `KO TF → peak → affected gene`. Pathway topology is no longer filtered by magnitude: any finite aggregate edge effect may participate in direct or indirect path construction. The only count limit is at most 3 paths per cluster (ranked by pathway contribution). Thus weak paths are retained and are not labeled `No route` merely because their contribution is small.

## 5. Automatically Selected Positive- and Negative-Effect Pathways

In addition to drawing the genes specified by `pathway_specified.png`, the script selects the target gene with the largest positive effect and the target gene with the largest negative effect for each of two pathway classes, automatically outputting four figures. These four figures use exactly the same radial cluster hierarchy, response colors, path filtering, and global aggregation rules as Section 4. Therefore, when candidates exist in all four categories, the total number of pathway figures should be **5** (1 specified-gene figure + 4 automatically selected figures):

- `pathway_direct_top_positive.png`: the gene with the largest positive `delta_rna_signed` among target genes with a direct regulatory edge from the target TF.
- `pathway_direct_top_negative.png`: the gene with the smallest negative `delta_rna_signed` among target genes with a direct regulatory edge from the target TF.
- `pathway_indirect_top_positive.png`: the gene with the largest positive `delta_rna_signed` among purely indirectly regulated target genes.
- `pathway_indirect_top_negative.png`: the gene with the smallest negative `delta_rna_signed` among purely indirectly regulated target genes.

If no candidate gene exists in the required direction for a category, the script skips that figure, so the actual number may be fewer than 5.

The `direct regulation` category requires the final target gene to have at least one `target TF→peak→gene` edge. If the gene also has indirect paths, they are displayed together.

The `purely indirect regulation` category requires no `target TF→peak→gene` direct edge but at least one complete indirect chain:

```text
target TF → intermediate TF → peak → downstream target gene
```

The upstream and downstream chain must be verifiable within the same cluster. Therefore, every propagation path in a purely indirect figure passes through an intermediate TF and contains no direct regulatory edge from the target TF to the final target gene.
For a concise figure, the complete filtering rules and visual encoding are defined by Section 4 and this section.

## 6. `tf_hierarchy.png`: TF Regulatory Hierarchy

This circular plot summarizes the regulatory hierarchy through which RUNX1 KO propagates via intermediate TFs to downstream genes.

- Center: RUNX1 KO.
- Inner ring: the 5 intermediate TFs with the highest joint contribution.
- Outer ring: the main downstream genes of each intermediate TF, up to 4.
- Red: positive or activating effects.
- Blue: negative or inhibitory effects.
- `*` after an outer-ring gene name: the gene is regulated by multiple intermediate TFs shown in the figure.

The joint contribution of an intermediate TF is defined as:

```text
joint_contribution = sqrt(upstream_contribution × downstream_contribution)
```

Where:

- `upstream_contribution`: the absolute effect of RUNX1→TF.
- `downstream_contribution`: the sum of the absolute effects of that TF on all downstream genes.

Inner-ring sector width is proportional to `joint_contribution`, and `J` in the TF label is the joint-contribution score. The geometric mean requires strong contribution on both the upstream and downstream sides, avoiding rankings dominated by a large effect on only one side. Outer-ring sectors are allocated within each TF according to the absolute effects of downstream genes.

## 7. `umap_cluster_bin_effect.png`: Relative KO Effects by Cluster/Bin

This figure uses UMAP coordinates from `rna_clustered.h5ad` and maps each modeled cell’s cluster and pseudotime bin to one KO-effect intensity. Cells in the same `(cluster, bin)` share the same intensity value.

**Each point in the figure represents a cell, not a bin.**

- Point position: the cell’s UMAP coordinates in `rna_clustered.h5ad`.
- Point color: the relative KO effect of the cell’s `(cluster, bin)`.
- All cells in the same cluster and bin have the same color value.
- Thus, this is a **cell-level UMAP display with cluster-bin-level effect coloring**, not an independently calculated KO effect for each cell.

`bin_min` in pathway-level records indicates the bin in which the effect first fires. Because effects persist into later bins during perturbation propagation, accumulate all pathway contributions with `bin_min ≤ current bin` for each bin. First calculate the net effect within each downstream gene, then calculate:

```text
cluster_bin_effect = sum_over_genes(abs(net_gene_effect))
relative_effect = cluster_bin_effect / max(cluster_bin_effect)
```

- Light gray: unmodeled cells or no usable perturbation effect for that cluster/bin (including missing/NaN); gray is not zero effect.
- Light yellow to dark red: relative KO effects from weak to strong across all cluster/bin combinations.
- `Cl n`: the cell-cluster label in the original h5ad.

This score represents the total downstream transcriptome perturbation intensity and does not retain upregulation or downregulation direction. It is suitable for comparing relative KO response strength across clusters and pseudotime stages and must not be interpreted as an independent single-cell effect estimate.

## 8. `umap_cluster_bin_mean_effect.png`: Mean KO Effects by Cluster/Bin

This figure is output in parallel with Section 7 and uses exactly the same UMAP coordinates, cell-coloring method, and palette, but a different intensity definition.

Section 7 uses **cumulative total load** (more affected genes means stronger); this figure uses the **mean absolute effect per affected gene** to remove amplification caused by having more affected genes:

```text
mean_abs_downstream_effect = downstream_abs_sum / n_affected_genes
mean_relative_effect = mean_abs_downstream_effect / max(mean_abs_downstream_effect)
```

- `downstream_abs_sum`: the sum of absolute net effects of all downstream genes in that cluster/bin.
- `n_affected_genes`: the number of downstream genes with `|net effect| > 1e-10` in that cluster/bin; when 0, the mean effect is recorded as 0.
- `mean_relative_effect`: normalized to `[0, 1]` across all cluster/bin combinations.

The two figures may produce different strength rankings: some clusters rank high in Section 7 because they cover many genes but do not stand out in per-gene mean effect, and vice versa. Use Section 7 to compare “total perturbation coverage” and this section to compare “mean perturbation intensity per gene.” This score likewise does not retain upregulation or downregulation direction.

## 9. `atac_accessibility_chromosome.png`: Peak Accessibility Changes by Chromosome

This figure shows genome-wide ATAC peak accessibility opening/closing after perturbation. Data come from `<RESULT_DIR>/atac_changes_merged.csv` (columns: `peak_id, chr, start, end, delta_accessibility_signed, delta_accessibility, n_clusters_observed, z_score, is_significant`), using all peaks without significance filtering.

- x-axis: chromosomes, naturally sorted as `chr1…chr22, chrX, chrY`; non-standard chromosomes are placed last.
- y-axis: peak genomic coordinates (bp).
- Red: increased accessibility, namely opening.
- Blue: decreased accessibility, namely closing.
- Color intensity: darker color for larger `|delta_accessibility_signed|`.
- Neutral color: changes close to 0.

Because the span of an individual peak (about several hundred bp) is invisible relative to chromosome length (about 250 Mb), the figure uses **fixed-height bars**: all bars have the same height, while their positions remain the midpoint of each peak’s genomic coordinates. Color intensity uses square-root mapping:

```text
effect_color = sign(delta_accessibility_signed) × sqrt(|delta_accessibility_signed| / max|delta_accessibility_signed|)
```

This mapping keeps the many weak effects (about 51.6% of peaks in D3 have `|Δ| < 0.01`) visible; the legend notes the nonlinear √ scale. If `atac_changes_merged.csv` is missing or lacks columns, this figure warns and is skipped without affecting other figures.

## 10. `atac_distribution.png`: ATAC Accessibility-Effect Distribution and Classification

This figure is the ATAC-side counterpart to the RNA distribution figure in Section 2 and consists of two panels. **The analysis unit is a peak, not a gene.**

### Left: Effect Distribution

- x-axis: signed `delta_accessibility_signed` (positive for opening, negative for closing).
- y-axis: number of peaks in the corresponding interval.
- Red bars: positive effects, namely opening.
- Blue bars: negative effects, namely closing.
- Solid black line: zero-effect position.
- Dashed red line: median accessibility change across all peaks.

### Right: Effect Classification

Classify by the magnitude threshold `|delta_accessibility_signed| > 0.01`:

- Open: `Δ > 0.01`.
- Close: `Δ < -0.01`.
- Stable: `-0.01 ≤ Δ ≤ 0.01`.

This classification likewise uses only a magnitude threshold and is not a statistical-significance test. The pipeline separately has a significance determination based on `atac_significance_zscore` (default `2.0`), whose threshold definition differs from this figure; in D3 data, that significant set contains only about 257 peaks. If `atac_changes_merged.csv` is missing or lacks columns, this figure and Section 9 are skipped together.

## Interpretation Notes

1. All results are model-predicted in silico KO effects and are not equivalent to experimentally validated causal conclusions.
2. `log2FC` represents predicted expression change; `R²` represents model-fit quality, and their meanings differ.
3. Red and blue colors indicate regulatory direction, not statistical significance.
4. Pathway-figure topology is no longer filtered by magnitude, but each cluster displays at most 3 paths (ranked by contribution); other undisplayed paths may still contribute to the final effect.
5. Gray in the cross-cluster heatmap indicates missing, unobserved, or NaN values and must not be treated as zero effect; white indicates an observed effect close to 0.
6. In pathway figures, `Missing` means there is neither a terminal-effect result nor a retained path; if there is only a path but the terminal effect is missing or NaN, it must be shown as gray/missing and not rendered as near-zero.
7. Red and blue in ATAC figures mean **accessibility opening (positive) / closing (negative)**. They correspond to the upregulation/downregulation directions in RNA figures but have different units, so numeric magnitudes cannot be compared directly.
8. `atac_accessibility_chromosome.png` uses a nonlinear square-root color mapping, and bar height is fixed; only position corresponds to genomic coordinates, and bar height does not represent effect size.
9. The `|Δ| > 0.01` threshold in the ATAC classification figure differs from the pipeline’s `atac_significance_zscore` significance criterion and must not be mixed with it.
